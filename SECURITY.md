# 🔒 Security Policy

### 🛡️ Private Key Protection
* Trae-GodMode is designed with **zero-telemetry** and **local-only routing**.
* Your API keys in `config/keys.json` are stored strictly on your local machine (`127.0.0.1`) and never transmitted to any third-party server.
* `.gitignore` prevents private keys from ever being committed to Git.
