# 🛠️ Troubleshooting & FAQ

### Q1: Trae updated and my patches were reset. What do I do?
👉 Simply double-click `1_CLICK_APPLY_PATCHES.bat` again. It will re-apply all patches to the new Trae version in 1 second.

### Q2: How do I know if the Key Pooler is working?
👉 Check the console window of `START_KEY_POOLER.bat`. It logs every request, model name, and active key in real time.

### Q3: How do I revert back to default Trae?
👉 Trae-GodMode automatically saves a `.bak` backup file next to `index.mjs`. Simply delete the patched file or run Trae's official installer to restore.
