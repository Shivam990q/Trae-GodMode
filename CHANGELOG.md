### 🎉 Genesis Release
- 🧠 **Full-Tier Reasoning Unlock:** Enabled `none` through `max` reasoning depths for all models.
- ⚡ **Zero-Friction Omni-Autonomy:** Auto-approved terminal commands, MCP tools, file deletions, and multi-step plans.

- 🔄 **Multi-Key Failover Gateway (`key_pooler.py`):** Sub-millisecond 429 rate-limit failover and round-robin load balancing.
- 🔓 **Unrestricted Model Studio:** Unlocked all disabled form fields in Trae's Edit Model modal.
- 🌐 **100% Universal Portability:** Dynamic `%USERPROFILE%` and `%LOCALAPPDATA%` path discovery across any Windows device/drive.
