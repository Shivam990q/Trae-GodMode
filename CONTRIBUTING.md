# 🤝 Contributing to Trae-GodMode

We welcome all contributions, bug reports, and feature requests!

1. Fork the repo.
2. Create your feature branch (`git checkout -b feature/EpicFeature`).
3. Test locally using `python scripts/verify_installation.py`.
4. Commit your changes (`git commit -m 'feat: add EpicFeature'`).
5. Push to the branch (`git push origin feature/EpicFeature`).
6. Open a Pull Request.
